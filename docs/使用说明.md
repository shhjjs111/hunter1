# Hunter1 使用说明

> 这是一份给第一次使用的人看的短说明。遇到问题先看最后一节「常见问题」。

## 1. 安装：解压即用

1. 下载 `hunter1-win32.zip`；
2. 解压到一个**纯英文路径**，例如 `D:\hunter1`（不要放在中文目录或桌面深层路径）；
3. 双击 `hunter1.exe`。

程序会在本机启动，并自动打开浏览器。数据保存在程序旁边的 `data/` 目录，
不需要安装 Python、Node 或数据库。删除整个文件夹即可卸载。

> Windows 可能提示「未知发布者」。这是当前版本还没有代码签名证书，不是病毒。
> 点「更多信息」→「仍要运行」即可。

## 2. 第一次配置

1. 打开「配置」页；
2. 填入一个 **OpenAI 兼容**服务的 `base_url`、模型名和 API Key；
3. 点「测试连接」，看到成功后再保存。

常见的 OpenAI 兼容服务包括 DeepSeek、通义千问、Kimi、智谱、OpenAI 等，
`base_url` 与模型名以厂商文档为准（多数以 `/v1` 结尾）。

**每个人用自己的 Key**：不要把自己的 Key 发给亲戚朋友共用，也不要把它写进
群里。Key 与用量都归各自账号，泄露后应立即到厂商后台作废。

API Key 只保存在本机的 `data/` 数据库里，不会上传到 Hunter1 的服务器
（本项目没有服务器）。但也正因如此：**不要把 `data/` 文件夹发给别人**，
里面有你的 Key 和求职数据。

## 3. 抓岗位、看匹配分

1. 打开「抓取」页，点「开始抓取」；
2. 等进度跑完，回到「岗位库」；
3. 在岗位详情里点「评分」，助手会按你的画像给出匹配分和理由。

抓取的是公开招聘列表页，不登录、不绕验证码、不自动投递。

## 4. 用手机访问（同一 Wi-Fi）

手机和电脑连同一个 Wi-Fi 后：

1. 在程序目录双击 `hunter1-lan.cmd`；
2. 电脑终端会显示两行：
   - `手机访问：http://192.168.x.x:8000`
   - `访问码：xxxxxxxx`
3. 手机浏览器打开上面的地址，输入访问码；
4. 输入一次后，这台手机会记住 30 天。

注意：

- 只在**自己家的 Wi-Fi** 下使用；不要在公司、咖啡店等公共网络开启。
- 拿到访问码的人都能使用这个界面。访问码只显示在电脑终端里，不要截图外发。
- 想作废所有手机：关闭程序，删除 `data/access_token`，再启动会生成新码。
- 手机访问的是**你这台电脑**上的数据；电脑关机后手机也打不开。

## 5. 备份与更新

- **备份**：关闭程序，把整个 `data/` 文件夹复制到别处。
- **更新**：下载新版 zip，解压后覆盖旧程序目录（保留 `data/` 不动）。
- 也可以在命令行运行：
  ```bat
  hunter1.exe update --source <新版 manifest.json 地址>
  ```

## 6. 常见问题

**端口 8000 被占用**
换一个端口：在命令行运行 `hunter1.exe serve --port 8001`，或关掉占用 8000 的程序。

**「测试连接」失败**
先检查 `base_url` 是否以 `/v1` 结尾（不同厂商要求不同）、Key 是否复制完整、
电脑能否正常访问该服务。错误提示里会尽量给出下一步动作。

**抓取显示失败 / 风控**
部分站点会临时限制访问或改版，失败会明确显示原因，不会假装抓到空列表。
换个时间再试，或只抓其他站点。

**手机打不开**
确认电脑和手机在同一个 Wi-Fi；确认 `hunter1-lan.cmd` 的窗口没有关闭；
确认 Windows 防火墙允许 Python/ hunter1 在专用网络通信。仍不行时，在电脑上
运行 `ipconfig` 查看「无线局域网适配器」的 IPv4 地址，用
`http://那个地址:8000` 打开。

**忘记访问码**
关闭程序，删除 `data/access_token`，重新启动会显示新码。
